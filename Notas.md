# Actividad de Git y GitHub

## ¿Qué es Git?
Git es una herramienta que lleva el control de los cambios que haces en tus archivos. Git guarda ese historial automáticamente y te deja regresar a versiones anteriores si algo sale mal. Funciona local, sin necesitar internet.

## ¿Qué es GitHub?
GitHub es la plataforma en línea donde subes tus repositorios de Git. Ahí puedes verlos desde cualquier lugar y, sobre todo, trabajar en equipo con otras personas. Además suma herramientas como Issues y Pull Requests que Git por sí solo no tiene.

## Git vs GitHub
- Git: el sistema que controla las versiones.
- GitHub: la plataforma web que usa Git y le agrega funciones para colaborar.
- Resumen: Git es el motor, GitHub es donde lo compartes con otros.

## ¿Qué es un commit?
Es como guardar un "punto de control" de tu proyecto. Cada vez que cambias algo y quieres dejarlo registrado, haces un commit con un mensaje corto explicando qué hiciste.

## ¿Qué es un branch?
Es una copia paralela de tu proyecto para trabajar sin afectar la versión principal (main). Si funciona lo que hiciste, lo integras después si no, no arriesgaste nada del original.

## ¿Qué es un Pull Request (PR)?
Es la forma de proponer que tus cambios de una rama se integren a la rama principal. Permite que otros revisen, comenten y aprueben antes de fusionarlo.
